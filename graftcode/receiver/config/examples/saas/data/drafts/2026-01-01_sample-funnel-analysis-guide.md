# A Practical Guide to Funnel Analysis

Funnel analysis shows where users drop off between signup and activation. Start with three steps and add more only when the data justifies it.

## Pick the events
Choose one event per step, such as signed up, created a project, invited a teammate. Name them consistently so the analytics stay readable.

## Read the drop-offs
A drop of 40% between two steps is a prompt to look at that screen, not a verdict on the product.
